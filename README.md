# 小车控制交接包

这是一个独立项目的小车控制交接包。原有 ROS 包名中保留了 `spore_patrol`，只是为了兼容现有树莓派环境，不要求使用原项目。适用对象是同一台 **WHEELTEC R550 PLUS 小车、C50C/STM32 底盘和原树莓派 5**。更换底盘、主控或固件后，不能直接假定协议兼容。

## 第一步：交给 Agent

在 Ubuntu 电脑上克隆仓库，把整个文件夹交给可使用终端的 Agent，然后发送：

> 请先完整阅读交接包中的 `AGENTS.md` 和 `给Agent的部署任务.md`，按说明检查电脑与树莓派，帮助我安装依赖、打开本地控制台并教我操作。先使用树莓派原有环境，不要自动重刷、覆盖或启动第二套底盘驱动。车辆运动测试由我在现场操作。

需要通过私下交接获取树莓派地址；树莓派与电脑须连接同一可互访的热点。若树莓派需要密码或 sudo，自己在系统提示中输入；不要把密码发给 Agent 或写进文件。

## 自行启动

从项目负责人处获取树莓派地址后，在仓库根目录执行：

```bash
cd console
./setup.sh
ROSBRIDGE_URL=ws://树莓派地址:9091 ./start.sh
```

将命令中的 `树莓派地址` 替换为实际地址。保持终端运行，浏览器打开 http://localhost:8765。首次安装需要网络。

## 包内文件

- `给Agent的部署任务.md`：Agent 的执行流程、检查和交付标准。
- `成员快速上手.md`：面向使用者的连接、遥控、录制和回放教程。
- `常见问题.md`：状态异常与排查。
- `console/`：运行在电脑上的控制台、安装脚本与启动脚本。
- `pi/`：树莓派底盘驱动源码、可选的独立恢复镜像与恢复说明。
- `tests/`：不连接真实小车的自动检查。

## 使用边界

控制链路：电脑浏览器 → 电脑本地服务 → 热点 → 树莓派 ROS 2 / rosbridge → USB 串口 → 小车底盘。电脑不需要安装 ROS 或 Docker；电脑和树莓派需要可互相访问的网络及安装依赖所需的网络。树莓派实际使用 Ubuntu 24.04.4 + Docker 中的 ROS 2 Humble；ROS 网络域是 77。

2026-11-17 交接时，原树莓派的 `humble` 容器、`spore-vehicle-stack` 和 `spore-rosbridge` 服务仍在运行；小车当时未连接。交接包内底盘驱动的主文件、协议和配置的校验值与当时树莓派源码一致。控制台完成了离线模拟测试和连接状态检查，但**尚未完成接车运动和实车轨迹回放验证**。运行中服务不代表底盘反馈或停车已验证。

本包不含热点密码、SSH 密钥、树莓派系统镜像、Docker 镜像、ROS 软件包离线缓存或用户录制数据；首次安装/重建需要网络。它不会将先前电脑上的浏览器录制记录自动带到成员电脑。
